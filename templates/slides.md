# Шаблон слайдов (Slides Template)


Создай шаблон краткой версии лекции для слайдов.

Формат:

# Слайды к лекции {номер}

## Слайд 1. Название

## Слайд 2. Цель

## Слайд 3. Learning Objectives

## Слайд 4. Проблема / Hook

## Слайд 5–8. Теория

## Слайд 9. Кейс

## Слайд 10. Управленческий вывод

## Слайд 11. Практика

## Слайд 12. Ключевые термины

## Слайд 13. Anti-pattern

## Слайд 14. Мостик к следующей лекции

Требования:
- каждый слайд содержит 3–6 тезисов;
- без длинных абзацев;
- можно использовать таблицы и короткие схемы.
