# Чек-лист ревью (Review Checklist)

Раздели чек-лист на блоки:

1. Структура
2. Методика
3. Архитектурная корректность
4. Базы данных
5. Интеграции и очереди
6. Стиль
7. Практика
8. Связь с другими лекциями
9. Финальный вердикт

Добавь пункты:
- есть цель и learning objectives;
- есть hook;
- есть теория;
- есть кейс;
- есть практика;
- есть glossary;
- есть anti-pattern;
- есть мостик к следующей лекции;
- нет лишнего кода;
- термины соответствуют glossary.md;
- нет утверждения, что одна БД подходит для всего;
- очередь не описывается как замена БД;
- выбор технологий объясняется через trade-offs.
