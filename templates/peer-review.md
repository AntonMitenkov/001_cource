# Шаблон взаимной оценки (Peer Review)

Используется на Лекции 7 для взаимной оценки архитектурных отчётов. Оценивающий не является автором работы.

## Оценка по критериям (шкала 0–2: 0 — отсутствует, 1 — частично, 2 — полностью)

| № | Критерий | Балл | Комментарий (обязателен при 0 или 1) |
|---|---|---|---|
| 1 | Полнота ADR: Context / Decision / Consequences заполнены, статус указан | | |
| 2 | Trade-offs: для каждого решения показаны ≥2 альтернативы и причина отказа | | |
| 3 | Соответствие learning objectives лекции по syllabus (см. specs/syllabus.md) | | |
| 4 | Практический результат лекции присутствует в работе как артефакт | | |
| 5 | Читаемость: термины определены до использования, структура ясна без устного пояснения | | |
| 6 | Нет «золотого молотка»: ни одна технология не подана единственно верной | | |

## Итог
- Сумма баллов: ___/12
- Вердикт: [ ] принято / [ ] принято с замечаниями / [ ] на доработку
- Обязательный развёрнутый комментарий (что улучшить в первую очередь): ______

Правило: peer review не переводит материал в статус finalized — итоговый вердикт за преподавателем.
