# Проектирование ИТ-решений: System Design с усиленным модулем по базам данных и интеграциям

Курс для студентов бизнес-информатики по проектированию верхнеуровневой архитектуры ИТ-систем.

## 1. Цель курса

Подготовить студентов бизнес-информатики к курсу "Базы данных" и научить их проектировать верхнеуровневую архитектуру ИТ-систем.

Студенты научатся:
- Переводить бизнес-цели в архитектурные решения
- Выделять домены и контексты системы
- Выбирать типы СУБД под задачи бизнеса
- Проектировать интеграции, очереди и брокеры сообщений
- Определять нефункциональные требования (NFR)
- Анализировать trade-offs архитектурных решений
- Создавать итоговый Architecture Blueprint системы

## 2. Аудитория

- Студенты направления "Бизнес-информатика"
- Слушатели, готовящиеся к изучению курса "Базы данных"
- Начинающие специалисты, желающие освоить основы System Design
- Требуется базовое понимание информационных систем и бизнес-процессов

## 3. Формат

- **Количество лекций:** 8
- **Продолжительность:** 80 минут каждая
- **Формат проведения:** Лекции + практические занятия + кейсы
- **Итоговая работа:** Architecture Blueprint спроектированной системы

### Структура курса:
1. Введение в System Design и перевод бизнес-целей в требования
2. Выделение доменов и контекстов (Domain-Driven Design basics)
3. Архитектурные стили и паттерны
4. Типы СУБД и выбор хранилища данных
5. Моделирование данных и ACID/BASE
6. Интеграции: API, очереди, брокеры сообщений
7. Нефункциональные требования (NFR) и trade-offs
8. Итоговый Architecture Blueprint и защита проекта

## 5. Как использовать репозиторий с AI-агентом

Этот репозиторий предназначен для генерации учебного курса с помощью AI-агента.

### Порядок работы:

1. **Изучите спецификации** (`specs/`) — AI должен понимать цели и структуру курса
2. **Проверьте базу знаний** (`knowledge/`) — источник фактической информации
3. **Используйте шаблоны** (`templates/`) — единый формат материалов
4. **Генерируйте контент** в `content/` согласно контрактам из `specs/content-contracts/`
5. **Ведите бэклог** в `tasks/backlog.md` — отслеживайте прогресс

### Команды для AI-агента:

- "Сгенерируй лекцию №X по теме Y, используя шаблон templates/lesson.md"
- "Создай практику к лекции №X, следуя templates/practice.md"
- "Проверь контент на соответствие контракту specs/content-contracts/lesson-contract.md"
- "Обнови глоссарий knowledge/glossary.md новыми терминами из лекции №X"

Подробные инструкции для AI-агента см. в файле `AGENTS.md`.

## 6. Правила генерации контента

### Общие принципы:

- **Соответствие спецификациям:** Весь контент должен соответствовать `specs/learning-outcomes.md` и `specs/syllabus.md`
- **Единый стиль:** Использовать шаблоны из `templates/`
- **Проверка фактов:** Сверяться с `knowledge/` для точности информации
- **Постепенность:** От простого к сложному, от бизнес-целей к технической реализации
- **Практическая направленность:** Каждый модуль содержит практику или кейс

### Требования к материалам:

#### Лекции:
- Соответствуют `specs/content-contracts/lesson-contract.md`
- Длительность материала: ~80 минут
- Содержат: введение, основную часть, примеры, выводы
- Ссылки на соответствующие разделы `knowledge/`

#### Практики:
- Соответствуют `specs/content-contracts/practice-contract.md`
- Закрепляют материал лекции
- Содержат задание, исходные данные, критерии оценки

#### Кейсы:
- Реалистичные бизнес-сценарии
- Требуют применения нескольких концепций
- Имеют варианты решений с trade-offs анализом

### Контроль качества:
- Использовать `templates/review-checklist.md` для проверки каждого материала
- Вести список изменений в `tasks/backlog.md`

## 7. Статус подготовки материалов

| Раздел | Статус | Примечание |
|--------|--------|------------|
| **Спецификации** | 🟡 В работе | Базовая структура создана, требуется наполнение |
| **База знаний** | 🔴 Не заполнена | Шаблоны файлов созданы, контент отсутствует |
| **Шаблоны** | 🔴 Не заполнены | Файлы созданы, требуют наполнения |
| **Контент курса** | 🔴 Не начато | Ожидает заполнения после подготовки specs и templates |
| **Задачи** | 🟡 В работе | Бэклог создан, требует приоритизации |

- 🟢 Готово
- 🟡 В работе
- 🔴 Не начато
