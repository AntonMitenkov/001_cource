ADR-001: Использование PostgreSQL для хранения заказов
Статус
Принято
Контекст
Системе маркетплейса требуется хранение заказов с гарантией целостности.
Заказ включает: клиента, позиции, суммы, статусы.
Недопустима потеря данных или частичное оформление заказа.
Ожидаемая нагрузка: ~500 заказов/сек в пике.
Требования регулятора: хранение данных в РФ (152-ФЗ).
Решение
Используем PostgreSQL как основную СУБД для домена «Заказы».
Последствия
Положительные
Полная поддержка ACID-транзакций
Зрелая экосистема (репликация, бэкапы, мониторинг)
Поддержка JSONB для гибких атрибутов
Соответствие 152-ФЗ при размещении в РФ
Отрицательные / Риски
Вертикальное масштабирование ограничено одним сервером
Сложность при необходимости шардирования
Необходимость квалифицированных DBA
Нейтральные
Команда имеет опыт работы с PostgreSQL
