# Диаграмма Исикавы (Рыбья кость)

## Определение

Диаграмма Исикавы (Ishikawa diagram, Fishbone diagram, Cause-and-Effect diagram) — инструмент визуального анализа причинно-следственных связей проблемы.

Изобретена: Каору Исикава (Kaoru Ishikawa), 1960-е годы, компания Kawasaki.

Используется в: TQM (Total Quality Management), Six Sigma, анализе корневых причин.

## Структура

Голова рыбы — проблема (след).
Кости — категории причин.

## 6 категорий (6M)

| Категория | Перевод | Описание |
|:---|:---|:---|
| Manpower | Люди | Квалификация, обучение, мотивация, усталость |
| Methods | Методы | Процессы, процедуры, стандарты |
| Machines | Оборудование | Серверы, сети, инструменты |
| Materials | Материалы | Данные, конфигурации, зависимости |
| Measurements | Измерения | Метрики, мониторинг, логирование |
| Mother Nature | Внешняя среда | Регуляторика, рынок, внешние системы |

## Применение в IT

### Пример: «Частые падения БД»
Люди:
Нет дежурного DBA ночью
Разработчики не знают лимиты запросов
Методы:
Нет процесса код-ревью SQL
Миграции без тестирования на стейджинге
Оборудование:
Диск на 90% заполнен
Нет резервного сервера
Материалы (Данные):
Таблица с 500 млн строк без индексов
Нет архивирования старых данных
Измерения:
Нет алертов на slow queries
Мониторинг только раз в 5 минут
Внешняя среда:
Пиковая нагрузка в Чёрную пятницу
Требование регулятора хранить данные 5 лет


## Связь с методом «5 почему»

Диаграмма Исикавы выявляет категории причин.
Метод «5 почему» (Тайити Оно, Toyota) углубляется в каждую причину:
Почему БД упала? → Переполнился диск.
Почему переполнился диск? → Логи не ротировались.
Почему не ротировались? → Нет настройки ротации.
Почему нет настройки? → Нет процедуры при развёртывании.
Почему нет процедуры? → Нет стандарта эксплуатации.
