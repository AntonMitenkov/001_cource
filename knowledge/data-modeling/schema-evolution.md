# Эволюция схемы БД и миграции

## Принцип: схема БД как код

- Схема БД версионируется в Git
- Каждое изменение = миграция (migration)
- Миграции применяются последовательно и воспроизводимо
- Откат миграции возможен (down-миграция)

## Зачем нужны миграции

- Команда работает с одинаковой схемой
- Изменения применяются контролируемо
- Можно воспроизвести схему с нуля
- Аудит изменений схемы
- Откат при ошибке

## Инструменты миграций

| Инструмент | Язык / Формат | Экосистема |
|:---|:---|:---|
| Flyway | SQL, Java | Java, Spring |
| Liquibase | XML, YAML, SQL, JSON | Java, Spring |
| Alembic | Python | Python, SQLAlchemy |
| Django Migrations | Python | Python, Django |
| Knex.js Migrations | JavaScript | Node.js |
