# Нотации ER-диаграмм

## Нотация Чена (1976)

Автор: Питер Чен (Peter Pin-Shan Chen), 1976.

**Элементы:**
- Прямоугольник — сущность
- Овал (эллипс) — атрибут
- Ромб — связь (отношение)
- Линии — соединения между элементами
- Подписи на линиях: 1, N, M — кардинальность

**Пример:**
[Клиент] --- (имя) --- [Клиент] --- (оформляет) --- [Заказ]

**Плюсы:** академическая, наглядная для обучения.
**Минусы:** громоздкая для больших схем.

## Нотация Crow's Foot (Воронья лапка)

Современная нотация, наиболее распространённая в промышленности.

**Символы кардинальности:**

| Символ | Значение | Описание |
|:---|:---|:---|
| `|` | Один (обязательно) | Ровно один |
| `| |` | Один и только один | Обязательная связь |
| `| <` | Один или много | Минимум один |
| `0 <` | Ноль или много | Может не быть |
| `0 |` | Ноль или один | Опциональная связь |

**Пример:**
Клиент ||---|< Заказ (один клиент → много заказов)
Заказ ||---|< Позиция (один заказ → много позиций)
Товар ||---|< Позиция (один товар → много позиций)


**Плюсы:** компактная, стандарт в инструментах (ERwin, MySQL Workbench, DBeaver).

## UML Class Diagram

Альтернатива для моделирования данных.

**Элементы:**
- Класс (сущность) — прямоугольник с тремя секциями: имя, атрибуты, методы
- Связи: ассоциация, агрегация, композиция
- Мультипликаторы: 1, 0..1, *, 1..*

**Пример:**

+----------+ +----------+
| Клиент | 1 * | Заказ |
+----------+----------+----------+
| имя | | дата |
| email | | статус |
+----------+ +----------+


## Сравнение нотаций

| Критерий | Чен | Crow's Foot | UML |
|:---|:---|:---|:---|
| Для обучения | ✅ | ✅ | ⚠️ |
| Для промышленности | ❌ | ✅ | ✅ |
| Компактность | ❌ | ✅ | ✅ |
| Поддержка в инструментах | ⚠️ | ✅ | ✅ |
